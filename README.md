Analog Clock (HTML, CSS, JavaScript)
This project is a simple analog clock built using HTML, CSS, and JavaScript. It displays real-time hour, minute, and second hands that update every second.

Features
	* Smooth real-time clock updates
	* Clean, responsive analog clock UI
	* Pure front-end (no libraries needed)

Technologies Used
	* HTML: Page structure
	* CSS: Clock layout and styling
	* JavaScript: Time tracking and hand rotation
